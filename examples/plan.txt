BUNDLE LOCATION FOR APPLY
Apply unmounts /data, so it refuses a bundle stored on /data, /sdcard or other
userdata-backed internal storage. Copy this directory to an external SD card
(or /tmp for a single recovery session) and set plan = that path in the Apply
request. The stage log and apply session must stay writable until <data> is
unmounted and both GPT copies are verified.

To apply, run the Apply ZIP with mode = apply, plan = this directory,
acknowledge_data_loss = yes and this exact confirm value:

unixnu 6081bdc305cf4ff593b698f4ebeb1c1d FIXTURESERIAL 67108864

DATA-LOSS WARNING
Shrinking F2FS moves file data and rewrites the partition table. A GPT backup
does not contain file contents, and restoring the old GPT cannot undo an F2FS
shrink. Keep a separate backup of userdata and metadata. Do not format either
partition and do not retry an interrupted apply.
